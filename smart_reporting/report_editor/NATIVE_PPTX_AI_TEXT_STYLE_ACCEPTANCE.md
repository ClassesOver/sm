## 2026-11-11 Agno 工具循环与共用进度增量

原生 PPTX 任务通过 `plan_slides` 使用任务私有 Agno Toolkit：`get_presentation_context`、`read_slide`、`propose_operations`。原有结构化 planner 供非原生调用兼容保留。模型只看到冻结授权对象，读取反映人工未保存文字、样式及几何；分页读取须覆盖完整内容，不能只读取末页绕过。整稿页序或主题提案须读取全部授权页，选区任务仍禁止调整页序和全稿主题。

提案工具校验对象身份及字段，转换文字样式为原生 `textFormatting`，与人工完整草稿合并后调用真实 `editor.preview`。预览失败或回执缺少有效 SHA256 时不登记候选，允许修正重试；并发或重复成功提交被拒绝。服务端再次校验和预览，用户显式采纳后才返回合并操作，源文件不被工具直接覆盖。工具预算按授权页的实际分页读取次数计算，并保留修正余量；31 页整稿逐页读取后提交页序调整的回归通过。纯 assistant 正文或 JSON 不作为可执行操作。预览期间取消维持取消终态，不发布候选。

真实 Agno 工具开始/完成事件进入现有任务事件流，保留 toolCallId 和成功/失败状态。四格式共用进度面板新增 23 个已注册工具的中文展示名，显式 label 优先，未知工具保留原名；不变更 SSE 协议。

验证分批执行，未重复全项目测试：PPTX 工具/边界/原生服务/旧 planner/取消回归共 37 项通过。真实引擎用例通过 python-pptx 独立回读文字、字号 24、粗体、颜色 123456、位置，并确认人工页序、斜体、背景和原始来源保留。Agno 使用 ScriptedModel，实际执行原生工具循环与事件流；不冒称真实 provider 验收。共用进度中文标签 29 项前端测试通过，四格式进度面板和 PPTX 候选回归另 15 项通过。Python 本轮生产和新增测试文件 ruff 通过。

仍待实现：固定源完整 `execute_slide_script` 等工具能力，图片/表格/图表/母版/动画等复杂写操作，四格式纯阅读与复杂组合任务的完整对齐；新构建、浏览器和真实 provider 端到端验收仍开放。
