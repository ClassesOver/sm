# XLSX 报表筛选字段切片器／时间线专项验收

固定源 GenOffice `f8c17004fb730df11f0f743164ffd8b4281bb38c`；本地 `1e4a0a34` 加工作区改动，日期 2026-11-14。对应账本 P09，改为 done_bounded；整体对齐仍 active。

报表筛选字段此前能通过透视字段面板保存，却不出现在切片器／时间线入口。本批使行、列、报表筛选三个区域均可投影成员；报表筛选使用已有 pageFilters 保存选中标签，全选恢复未指定 selected。弹窗和工作表控件浮层共用选择状态投影，避免重开误显示全选。其他字段的报表筛选及行列手工筛选保持。

原生控件读取 pageLevelItems/pageHiddenItems，缓存成员索引与透视缓存一致。日期时间线刷新更新对应 pageFilters，并按既有区间重新筛选当前日期。源删除部分已选成员时，重算保留仍存在的选择交集，避免失效标签写入缓存。所有已选成员消失、交集为空仍明确拒绝刷新；没有把此情况降为全选。未知外部控件、共享缓存、分组字段和无效日期的原有保护继续适用。
