# 编辑器 AI 任务与工具栏

编辑器的 Ask AI 使用会话内统一任务 API，领域服务继续拥有原生 `editId`、
`candidateId` 和产物溯源。支持 document-selection、slides-edit、workbook-edit、
chart-edit、table-edit；PPTX 图表也使用 chart-edit。

## 协议与生命周期

各格式原有 `/api` 前缀下提供：

- `POST ai/tasks`：kind、instruction、target、snapshot、可选 idempotencyKey。
- `GET ai/tasks/{taskId}`：状态、候选、告警、native 原始响应；waitMs 最多 1500。
- `POST ai/tasks/{taskId}/accept`：携带生成时对应的 snapshot。
- `POST ai/tasks/{taskId}/cancel`、`reject`：取消任务或放弃候选。

服务端状态为 queued/running/ready/accepted/cancelled/failed。accepted 只确认候选，
不代表浏览器已应用，更不保存或发布报告。重复 start 使用同一幂等键，重复 accept
仍校验快照。本地控制器分别维护 unapplied/applying/applied/undone，应用失败保留
候选供重试。关闭侧栏继续轮询；销毁会话取消任务并忽略迟到响应。

任务随现有单进程服务运行，保留约一小时，不提供跨进程恢复。过期或重启后返回
任务不存在，用户可重新生成。文档生成有超时和服务关闭清理。

## 草稿边界

- 正文使用 ProseMirror 映射跟踪选区，其他段落编辑不使候选失效；引用标记保留，
  修改选区后拒绝覆盖。采纳和撤销使用原生编辑事务与历史。
- PPTX 复用保存的校验及编辑引擎生成临时草稿快照，包含未保存修改；保持原始
  slideIndex/elementId，不创建修订。新增草稿对象不会被误识别为可修改原生对象。
- XLSX 包含当前操作集合及源文件身份，采纳时由服务端重算 snapshotSha256。
- 图表和表格保留领域预览、模板、分页、数据来源与原生候选身份；统一任务 ID
  只用于传输，不用于 previousEditId 或保存时的 candidateId。

AI 采纳仅更新草稿。正文在 AI 采纳后暂停自动保存，包含之前自动保存尚在途的
场景；点击保存或显式导出时才保存候选。Office 保持单独保存及新修订行为。
旧正文流式 rewrite 和原有领域 API 保留兼容。

## 前端职责

- ai-task.ts：协议类型、带幂等键的传输、领域 adapter 接口。
- ai-task-controller.ts / ai-task-session.ts：任务控制与共享侧栏接线分离。
- asset-task-adapter.ts：图表/表格原生身份与任务身份映射、公共轮询。
- ask-ai-panel.ts：五类会话容器、预览区域、后台完成通知。
- toolbar.ts / shell.ts：公共、格式、上下文栏；注册动作、刷新状态、防重复点击。

document、PPTX、XLSX 仍按格式动态加载，Univer 内部工具栏保留。
共享层不负责保存、发布、溯源或绘图实现。

## 验证

前端执行 npm test、npm run build、npm run build:slides、check:budget 和 test:budget。
全量测试中的旧采纳时序和保存函数测试夹具已更新，并针对失败文件复测。
后端针对任务协议、正文兼容、Office 编辑与发布非阻断契约运行测试；不重复
完整 Python 测试套件。

## Ask AI 功能迁移核对

统一组件需保留原有审阅能力，不能以协议 JSON 代替面向用户的领域预览：

| 能力 | 接入方式 |
| --- | --- |
| 正文润色、精简、扩写、专业语气 | 共享侧栏的四个推荐操作；选中后可补充要求 |
| 正文差异审阅 | 差异高亮、前后对比、原文、候选四个视图；内容以文本节点渲染 |
| PPTX 修改明细 | 逐页对象、文字差异、位置与大小、页序、主题；以当前草稿为对比基线 |
| XLSX 候选 | 单元格地址、值、公式与样式摘要；展开查看完整操作明细 |
| 继续调整与重试 | 推荐指令、常见微调、显式重试、保留输入；生成阶段可取消 |
| 快捷键 | Ctrl/⌘+Enter 生成；审阅时 A 采纳、C 继续调整、X 拒绝；输入和后台会话不触发审阅动作 |
| 连续编辑与撤销 | 正文采纳后更新选区锚点；下一轮生成或拒绝不丢失上一轮撤销入口 |
| 图表/表格已有能力 | 继续使用领域模板、标准预设、分页、对比、来源与回执；由原有回归测试覆盖 |

共享会话展示任务告警、当前目标、后台完成通知和单独保存提示。
当前正文差异是侧栏文本审阅，PPTX 是逐项变更预览；未恢复为编辑画布内的逐块差异批注。

## 体验优化

- 工具栏公共、格式、上下文区域独立滚动，公共栏内保存按钮保持可见。
- Ask AI 保留覆盖式侧栏：默认 560px，桌面支持 360–800px 调整并记忆宽度；
  768px 及以下全屏显示。关闭只收起，保留会话、输入和滚动位置。
- 任务会话默认折叠对话和详细说明，预览优先；后台完成不抢焦点，提供查看新结果入口。
- 采纳后显示撤销和可选定位目标；定位接口 `AITaskAdapter.locateTarget` 返回是否成功，
  定位失败保留侧栏并显示原因。正文使用映射选区，PPTX 使用修改对象，XLSX 使用采纳前选区。
- 空输入禁止提交；重复提交不会创建多个任务；差异新增同时使用下划线和颜色表示。
- 用演示数据及模拟 AI 响应检查了三种编辑器在 1920、1366、1024、390px 的页面布局；
  真实模型端到端调用仍需另外验证。

### 长内容审阅与输入细节

正文和 PPTX 文字差异增加上一处/下一处导航及当前位置提示。差异计算设置工作上限，
超限时提示使用完整前后对比，原文及候选仍可完整查看。
工作簿单元格变更每页 50 项，支持翻页；完整操作 JSON 仅展开时生成。
修改要求显示 2000 字符限制，超长微调不截断或覆盖原有输入。
取消后可立即重新生成，迟到响应通过原有任务代次检查隔离；查看结果按滚动容器坐标定位。

### 应用工具栏精简

顶部不重复提供加粗、斜体等原生排版动作。正文常用操作为保存、目录、导出、搜索、来源与 Ask AI；
历史、分享、专注、设置和快捷键移入更多菜单，注册动作继续复用原按钮。
菜单支持方向键、Home/End、Esc 和点击外部关闭；打开菜单时收起其他侧栏，任务继续运行。
