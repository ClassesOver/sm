# 已有图片文字层级切换计划（2026-11-14）

目标：已有安全页面直属图片可切换到文字下方或上方，保留像素、矩阵/范围、原文与其他对象，支持原草稿预览确认、撤销恢复和下载。

方案：固定源 ImageLayer 为 belowText/aboveText，PageImageRef.aboveText 按页面首个文字对象分界。基于既有 firstTextIndex/RemoveObject 和引擎 InsertObjectAtIndex：下方插入首个文字前，上方追加页尾，其他对象相对顺序不变。复用 transformExistingImage，layer 单独使用，不与几何/像素/删除混合，不宣称任意图层面板或桌面全等价。

范围：页面直属、身份唯一、有直属文字、页面无Form对象且引擎支持精确插入的安全来源；沿用静态填表元数据与受保护来源限制。无文字、含Form/模板、同层无变化拒绝。层级不是安全擦除。
