# 已有图片删除计划（2026-11-14）

目标：沿用已有图片身份、草稿、预览确认和修订下载链，删除一处实际图片绘制对象，保留原来源和其他对象。

方案：固定源 ImageEditInput 含 deleteImage；复用已有 PDFium RemoveObject/Destroy/GenerateContent/saveDoc 片段（现有背景预览已使用），扩展 transformExistingImage 的 remove:true 分支，rect 只绑定原图像范围，不能与移动/替换/像素编辑混合。不引入新发布/签发步骤。

范围：身份唯一、页面直属且处于 CropBox 内的安全图片。共享像素流可删除一处绘制；模板内/重叠歧义/保护或带静态填表元数据来源拒绝删除，避免破坏关联记录。属于逻辑移除，不保证文件中清除图片资源，安全擦除仍用现有涂黑。前后层级另批处理。
