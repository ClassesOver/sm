## 设计与范围

1. 鼠标空白起拖框选，超过 4 屏幕像素才形成选择；反向拖动和
   Ctrl/Meta/Shift 追加选择可用，交集使用 Konva 当前对象旋转外接框。
   排除背景、装饰及无权限对象；离开、失焦、切页、缩放或几何更新取消拖动。
   框选本身不产生编辑草稿，触摸沿用单点选择。
2. 层级复用固定引擎 `reorderElement`，四方向为 front/back/forward/backward。
   多选保持原相对顺序，一步上/下移让选中连续块越过一个未选相邻对象。
   完整来源页顺序写入 `elementOrders`，每页最多 500 个对象；恢复、Python
   和桥接均严格校验，不允许改变只读对象彼此的相对顺序。
3. 层级在页面复制、版式重建之前按来源 ID 写入；同批其他文字、几何、裁切
   修改继续绑定来源对象。UI 有待保存的版式/尺寸/删除时先保存再调层级。
   无变化不记历史，回到来源顺序移除该层级记录，其他草稿保持。
4. 来源上下文菜单调用 `arrangeActions.reorderSelected`；固定源 Ribbon 没有
   层级回调或图标。本地 Ribbon 适配同一动作，并明确使用 Lucide 图标，
   不宣称这些 Ribbon 控件为源界面原样复制。

## 组合调查

`materializeSlide` 会重建整页 parse-time ID；`groupElements` 过滤未知 ID 后
仍可能成功，`ungroupElement` 未完整合成组旋转/翻转，连接线跟随只查顶层对象。
因此本批不直接开放组合/取消组合。后续需要严格目标校验与稳定身份映射，
先限定普通、无动画/连接引用、无旋转翻转和无嵌套的单次操作再扩展。
