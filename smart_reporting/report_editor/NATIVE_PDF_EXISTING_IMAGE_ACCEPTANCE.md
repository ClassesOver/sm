# PDF 已有图像移动与尺寸调整

## 实现范围

- 编辑真实 content-stream 图像对象，不插入 Stamp，不以覆盖图片代替原对象编辑。
- 移动与尺寸调整保留原始像素、对象自身非轴矩阵方向及页面旋转。输入是原始 PDF user space 坐标。
- 支持页面直接图像和独占 Form 中图像；独占 Form 经固定源 liftOutOfForms 提升后编辑。共享 Form 和同页 2pt 容差内存在歧义的对象不可编辑。
- 每次仅一个 transformExistingImage 操作，不能混用其他操作；目标位于 CropBox 内，宽高至少 3pt。
- 不包含 OCR、像素裁剪、图片替换、删除、图像旋转或图层调整。
- 非默认 UserUnit、签名/保护/表单/批注及异常页框暂拒绝 capability；返回具体理由。策略复用 staticTextAvailability 的安全检查。

## 接口及产物保留

- inspectExistingImages(bytes) 返回 existingImages 及 capabilities.editExistingImage / editExistingImageReason。
- 图像 identity 绑定 source SHA、页、枚举序号、原 bounds、raw pixels + matrix SHA；writer 前重读来源严格匹配。
- transformExistingImage(bytes, operation, expectedSha256) 操作严格仅有 kind/sourceSha256/pageId/imageId/expectedImageSha256/rect。
- writer 前失败返回来源 bytes + skip；writer 已返回后，输出 inspect、像素、正文、页面结构复核失败仍返回生成 bytes + output_review_failed 告警，applied 索引为空。不可宣称“保留原文”或“未执行”，以实际 PDF 为准。
- previewDigest 绑定操作、实际输出 SHA、applied 与 skipped；root 接实际预览和服务强制确认。
- 前端 bindPdfExistingImagePanel 提供真实图像选择、X/Y/宽/高数值编辑、readonly/unavailable/过期 snapshot/独立操作守卫和 incompleteReason。
