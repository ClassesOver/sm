# 3D 组件补丁

`@d3fc+d3fc-label-layout+7.0.4.patch` 为greedy策略增加可选 `fixed` 矩形：参与原生碰撞评分，但不生成移动候选。应用用它表示球体/图标的固定屏幕区域；原策略也移动这些区域，而应用只采用名称位置，导致评分时以为图标已经让开。补丁在现有ESM策略中跳过固定矩形的候选枚举，不改变原生评分；未标注 `fixed` 的矩形仍可移动，升级时核对上游是否已有固定障碍支持。

同一策略在提供bounds时将候选位置约束到该视口后再评分，避免先按越界位置评分、应用再裁回时引入新的重叠。固定区域保留原坐标，评分仍使用组件原生碰撞面积；未设置bounds的调用不增加约束。小图的名称尺寸均小于视口，不以此补丁保证任意超大矩形可容纳。

`three-forcegraph+1.43.6.patch` 与 `three-render-objects+1.43.0.patch` 同时改善旋转后的适应视图。
原图组件合并所有几何包围盒为一个世界坐标大盒，渲染组件再适应该大盒的八个角点；
斜向图会为实际上没有图形的组合角点留出空间，造成过度缩小。
图组件现保留每个几何盒的角点，同时保留原有x/y/z范围；渲染组件沿用原有相机距离公式，
只将候选点改为这些角点，普通不含corners的包围盒仍用原八角点。
距离计算使用reduce，不把随图规模增长的角点列表展开为Math.max函数参数。
应用仍调用组件原生zoomToFit，不增加相机控制器、布局算法或自动放大动作。
补丁只覆盖当前构建实际使用的ESM入口；两份需要一起保留，升级时重新核对源码和视觉。
从原始依赖重应用两份补丁已通过。普通/超长复杂fixture需检查全图与追踪/直接关系适应边界，
对照同三视口截图核对整体大小；小图鼠标与触控回放检查相机动作与现场恢复。
此优化不证明复杂图整体可读性或任意规模性能通过。

`three-render-objects+1.43.0.patch` 修复当前 Vite 使用的 ESM 入口中的快速点击拾取时序。
原实现每50ms更新悬停命中，pointerup 延后一帧发出点击；快速轻触可能在这50ms内结束，
从而把节点点击发给旧的空白命中。补丁在非拖动的 pointerup 后清除拾取节流时间，
让下一渲染帧在点击回调前刷新命中；拖动抑制逻辑和组件相机控制保持原样。

同一补丁将中键pointerup转发至已有onClick，复用原生节点拾取；组件原版只转发左键/右键，
导致图节点不满足中键后台开任务的设计要求。应用根据event.button=1选择既有后台任务操作，
不通过模拟左键、解析标签或自建拾取器实现。中键拖动仍被组件clickAfterDrag=false抑制。

`npm install` / `npm ci` 的 postinstall 使用成熟工具 patch-package 应用补丁，失败时终止。
升级组件时重新验证；上游修复后删除补丁及不再需要的 patch-package。
此补丁只修改当前实际消费的 ESM 入口，不声称修复组件的其他发布格式。

回归：启动 fixture 服务后执行 `node smoke/evidence-3d-touch-fixture.mjs`。
脚本清空鼠标悬停，再用 Playwright 快速触摸点击实际球体；不得用延长按住时间掩盖问题。
现有 `node smoke/evidence-3d-fixture.mjs` 覆盖鼠标点击、双击、旋转/滚轮和相机操作。
其中先使用真实画布中键创建后台任务，再用Control、Meta及右键重复打开检查复用；
Control+Shift检查前台激活，后台操作清空悬停后比较画布保持一致。
