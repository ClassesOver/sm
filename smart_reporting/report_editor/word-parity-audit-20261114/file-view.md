## Findings and interpretation

High-confidence functional gaps: new blank document; legacy/ODF/HWP import; editor Open and Save As commands; AI filename; encrypted DOCX open/save lifecycle; Word page-image export; deliberate document print/range UI; web/read/multiple-page/split views; dark page; editable/reorderable navigation headings; Go To dialog; live status page/selection word counts; preferences units; shortcut help and major App/Electron keyboard bindings; full contextual action surface. Existing disabled placeholders make many of these absences directly observable in local source (`docx-ribbon.ts:pendingGroups`, `docx-view.ts:reason`), rather than inferred from label mismatches.

Working view commands are real: percentage zoom/fit, ruler, gridlines, outline, navigation, page thumbnails, body find/replace and pagination preview have mounted local callbacks. HTML/Markdown exports are concrete source-helper integrations. PDF/save paths are substantive host adaptations using native operations and immutable revisions, not empty shells; they must not be called full upstream save/print serialization parity. Downloadable artifacts remain available alongside validation issues through `native-session.ts:renderResult`.

No upstream document-properties editor or document-version-history browser was found in App/Ribbon/native menu inventory. Therefore those requested audit dimensions are source-limited; source code identifiers containing `history`, `properties`, project chat history or table properties must not manufacture Word feature requirements. Browser new-tab/window/close/fullscreen and registered-URL opening are legitimate host substitutions, while their unimplemented in-product command labels and missing keyboard callbacks are separately recorded.

Additional upstream entrypoints checked beyond Ribbon: native menu `buildDocsMenu` (File/Edit/View/Insert/Format/Table/Tools/Window/Help), `docs:*` and `win:*` IPC registrations in main/docs-main.ts, preload desktop surface, argv/openable-extension helpers, print dialog, preferences and shortcuts dialogs/catalog, status footer, start/recent screen, custom context menu, recovery/autosave/close guards, password and explicit/headless export pathways. AI, formatting, table, mail-merge, review and layout command internals remain owned by parallel audit domains; this document records their non-formatting entrypoint gaps without claiming their functional internals absent.
