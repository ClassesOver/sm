## Principal gaps

1. Table style preset/document style selection and six table look switches have no working local dispatch.
2. Insert Cells/Delete Cells/Split Table/delete whole table and source right-click table/object surfaces are missing. Individual row/column operations, merge/split and property operations exist under narrow source and same-batch guards.
3. Shape/Textbox/WordArt insertion is real; existing object Shape Format controls and rich text/arrange are not delivered.
4. Picture byte workflows and whole-block formats are wired; inline/photo-box source coverage and z-order are narrower/missing.
5. Draw writes PNG+vector annotations; source pen preset gallery is not migrated. Design preset themes/fonts/colors are materially wired end to end.
6. Do not count unsupported Microsoft Word features as migration gaps: source chart insertion is only bar/line/pie; actual source Shape Format has no demonstrated full effects gallery.

## Evidence limits and delivery

This is static source evidence. It does not assert browser interaction or download/reopen fidelity beyond the explicit bridge readback assertions. Delivery operations flow from frontend docx-main.tsx collectOperations into native draft execution and bridge/edit-docx.ts, which calls saveDocx and rereads output. Source native Word engine writer is packages/docx-engine/src/patch.ts:saveDocx, fed by editor/convert.ts:pmDocToSavePlan and file-actions.ts:907. Table model writer is generate.ts:generateTableModelXml; inserted objects use buildTextboxParagraphXml/buildShapeParagraphXml/buildWordArtParagraphXml/buildLineParagraphXml. Local pending object validation intentionally rejects arbitrary genXml. Existing nested tables have specialized text patching, not general table structure parity.
