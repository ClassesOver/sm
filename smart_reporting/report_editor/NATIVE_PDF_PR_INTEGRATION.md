# PDF PR 隔离集成说明

2026-11-11；合并基线 `302517bfca0fee2bdf6a7e04edfe272db22462ec`；PR #215。

本 PR 收录本会话累积的 PDF 文字编辑、Office/文本转换、表单设计及必要的阅读、审阅、派生产物交付能力。OCR 不在本次交付范围。独立 Word、Excel、管理端功能不纳入本 PR；Word PR #214 已在基线中完成 DOCX 引擎迁移，本 PR 仅将 PDF 转换导入、Docker 源码依赖和运行包许可适配到 `doc_engine/packages/docx-engine`，继续复用基线 XLSX/PPTX 引擎。

## 验证证据的适用范围

`NATIVE_PDF_*_ACCEPTANCE.md` 记录原开发树各批次的分层证据与限制，不代表本 PR 的合并组合重新通过浏览器或宿主验收。最初整理时核对的 49 个前端、192 个引擎清单文件、955 个 bundle inputs 属于原开发树；后续不同隔离基线的输入和输出身份不能混用。

PR 最初基于 `9f2c494` 整理，随后同步 XLSX PR #213。执行用户授权合并时，目标又合入 Word PR #214；当前已完整保留最新 Word 的来源清单、配置与 API，仅补 PDF 必需增量。部分中间前端构建发现 npm workspace 反向链接指向主脏树，不能作为完全隔离验收；最终已纠正 ignored 依赖链接，并重新记录实际打包输入，而非仅检查目录链接。

当前合并组合的定向结果：

- 前端 21 项专项通过，包含 API、实际 serializer 和字体相关路径；Vite 构建通过。最终 Rollup 5,141 个文件逐一记录 realpath/SHA，837 个隔离工作区文件，无主脏树或其他工作区业务源码泄漏，构建后复核无变化。
- 前端来源清单保持 Word 基线原样；249 项 LOCAL 与 248 项固定上游来源均核验一致。Vite 完整保留基线内容，仅新增两条尚缺的 PDF controls 分块规则。
- PDF 分块全部通过基线预算，本 PR 未提高限额；最终 main 为 220,661 字节。
- 全局分块仍有两项超限：`workbook-engine` 为 419,537 字节（阈值 405,504），`workbook-icons` 为 280,818 字节（阈值 280,576）。未做 base-only 构建，不能归因为既有问题，也不沿用之前组合的包大小结论。
- PDF bundle 和运行包构建通过，955 个实际输入无业务源码泄漏，141 个共享源码输入与当前基线逐字一致；CLI SHA-256 为 `f853177a00142ebf601f1aea11484c871fc621e538c755e4d2038c42eb500fbc`。三引擎来源说明及许可齐备，全部本地输入位于 Docker 复制的源码范围内。
- 六个转换测试文件共 30 个目标用例通过；187 项 PDF LOCAL 及 converter 本地哈希一致。固定上游哈希保持上游身份，不以本地适配哈希替代。
- 新基线 DOCX 单入口运行包独立构建，244 个输入中 113 个共享源码与当前基线一致，无主脏树源码泄漏。
- 后端当前组合 90 项专项通过、2 项排除：AGENTS 登记的 11 条非阻断契约展开 69 项，原生 Word 发布 7 项，页面提取 HTTP 故障 14 项。跨工作区运行包许可专项另 1 项通过。实际文件缺失或身份变化的拒签边界保留，异常复核不阻断可核验的实际下载。

本次未重复完整项目测试；不同基线或依赖污染的重建均针对实际输入变化。未在新组合上重跑完整浏览器、Writer、Calc 或 Impress 验收，构建和专项成功不等于完整视觉或业务验收通过。复杂 fixture 按同一段落内的实际文字验证，允许合法链接 run 边界，保留显式换行和原有内容、字体、表格与几何要求。

## 发布与已知限制

实际文件身份可核验时，回执、登记或后置验收异常保留下载链接，同时返回具体告警；实际文件缺失或身份不匹配时不签发对应产物。新派生保存仍保留 `validation.ok=false` 或明确待核状态，不标记业务验收通过。

整体 PDF 对齐、复杂版式和字体完整保真仍未完成；XFA、任意复杂多 Widget、签名与保护来源等限制以 `NATIVE_PDF_ALIGNMENT_STATUS.md` 为准。原开发树的字体显示证据不能泛化为本次合并组合的宿主验收。用户已在知悉限制后授权合并，预算与保真告警继续保留。

最终本地证据为 `/tmp/pdf-pr-215-merge-{frontend,engine,backend}-evidence.json` 和对应日志；大产物以同名路径链接至 `/dev/shm`。生成运行包、构建输出、依赖目录和原始日志不提交。PDF fixture 与字体版权文本保持原始字节，差异空白检查排除这些原样证据文件。
