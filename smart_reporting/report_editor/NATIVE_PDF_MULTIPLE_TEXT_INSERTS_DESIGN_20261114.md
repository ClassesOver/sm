# PDF 多段文字插入

延续已授权的 PDF 对齐工作。本批消除每段 insertText 必须单独保存的限制；用户可跨页连续插入、统一撤销/恢复、预览及保存。保持既有字段、来源、页面几何和文字参数校验。仅允许 insertText 互相组合，其他编辑组合仍拒绝。

方案：复用 insertStaticText 顺序写入，各操作在首次写入前绑定原始来源并校验；执行时仅由服务端按原页序映射中间产物身份。与新增批量底层 writer 相比，复用已验证的字体、对齐、独立回读逻辑；代价是每段会重复加载文档。沿用现有 500 项后端预算，不另增上限。

回执必须保留原来源身份和操作索引，摘要绑定完整输入与最终字节；失败或复核告警不得丢失已经生成的字节。未写入段落可被跳过，但不得误报已应用。不修改发布/签发链。不包含段落 reflow、跨对象改字或其他操作混用。
