## 四项可复现问题与处理

1. **涂黑后的关联批注仍可恢复**：原实现删除根注释的页面槽位，但区域外回复的 `/IRT`
   仍可指向它，pypdf 可读回 `CONFIDENTIAL_ROOT_9182`。现在复用已有完整引用计数扫描，
   在 PDFium 执行前验证命中批注仅有一个页面引用，并拒绝共享外观、结构/弹窗/附件关联及
   无法证明安全的图。普通独占便签仍可涂黑。复杂线程采取安全拒绝，不声称已支持整线程涂黑。
2. **N 合 1 丢失可见批注与表单值**：固定 `mergePagesBytes` 只嵌入页面内容流。
   现在通过已固定 PDFium 2.15.1 的 `FPDFPage_Flatten(page, FLAT_NORMALDISPLAY)`
   先将可见外观转换为页面内容，再调用原有排版引擎。没有可确认外观的来源拒绝处理。
   标签、图像、签名笔迹与表单外观成为静态内容；交互、批注正文元数据、书签/附件不承诺保留。
3. **拆分页丢失 AcroForm 字段**：复制 Widget 不会复制有效的文档级字段树。
   当前明确禁用含表单的拆分页，前后端均拒绝，保留来源修订；动态 XFA 两种排版均拒绝。
   普通页面 2/4/9 拆分保持开放。完整表单树/Widget 复制重映射仍是后续缺口。
4. **按段动画引用过期**：先给三段文字添加动画，再将文字改为一段，曾输出指向不存在段落的
   `pgRg`。现在 UI 按待保存文字计数，将文字与有效动画放在同一个历史快照中；删除越界动画会
   明确提示且可撤销。服务端按修改后文字验证新增及已有引用，草稿恢复也按恢复快照而非旧来源计数。
