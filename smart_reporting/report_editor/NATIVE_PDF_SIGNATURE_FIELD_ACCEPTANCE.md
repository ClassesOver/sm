# 原生 PDF：可视签名放入已有签名字段 验收记录

日期：2026-11-14　基线：`origin/code` `0ce3aa10`（已含上游 edaec904“整合四格式原生编辑器与桌面 UI”）

## 范围与取舍

- 本轮优先项“已保存链接的编辑（改 URL/目标页、删除）”**不可行，未实现**。经核查：
  - 固定源 GenOffice 的 `LinkLayer.tsx` 只把已保存链接渲染成点击跳转（URL 外开、dest 跳页）。
  - 固定源 edit-ops 只有新增 `addDrawing`（kind link）。
  - 固定引擎 `AnnotDeleteInput` 只覆盖 markup/note/polygon。
  - 上游 `pdf-saved-links` 同样只读跳转。
  - 因此没有可逐字移植的 Link 改写或删除写入器。按约定，本轮改做“签名字段绑定”。
- 签名字段绑定移植自固定源 `openSignatureDialog(target)` 与 `placeSignatureInField` / `signatureDrawingForField`：
  - 布局：8% 内边距（取字段宽高较小值），等比缩放后居中。手写笔迹的 y 轴翻转到 PDF 坐标，线宽 1.6。
  - 写入：桥接直接复用固定引擎 `setVisualSignatureMetadata`，在 Ink 或 Stamp 上写 `/GenOfficeFormField` 与 `/Contents`。
  - **不写 `/V`。这是可视签名，不是证书数字签名。** 上游的数字签名只读面板（`digitalSignatures`）不受影响，两者模型键不同。
- 身份：与 removeDrawing 同一套方式，`fieldId` 加字段字典摘要 `expectedFieldSha256`。草稿中只保存身份，不保存字段名。
- 不做的范围：证书签名、OCR、加密来源。XFA、加密或带 Perms 的来源中，签名字段一律只读。

## 规则（整批先验后写）

| 情形 | 结果 |
| --- | --- |
| 字段不存在，或摘要已过期 | 拒绝 `pdf_signature_field_identity_invalid_or_readonly` |
| 已有证书签名（有 `/V`） | 不可绑定：“此签名字段已有证书签名，写入任何内容都会使其失效” |
| 已有可视签名（已有注释的 `GenOfficeFormField` 指向该字段） | 不可绑定 |
| 多控件签名字段，或控件页面/位置无法确认 | 不可绑定 |
| 签名不在字段所在页，或超出字段框（容差 0.5pt） | 拒绝：“PDF 签名须位于所选签名字段的范围内” |
| 同一批中同一字段绑定两次 | 拒绝 |
| 非 ink/image 形状携带 signatureField | 拒绝：“PDF 签名字段只接受手写或图像签名” |

## 前端（与上游签名对话框集成）

- 上游 `bindPdfSignatureDialog`（固定源 `SignatureDialog`：手绘/输入/图片、我的签名）**行为与界面不变**。
- 在其 `onConfirm` 之后增加放入位置选择：
  - 当前页序中有非空白页上、可绑定、且草稿中尚未使用的签名字段时，弹出“放入位置”对话框 `dialog.pdf-sign-target-dialog`（`aria-label="签名放入位置"`）。
  - 选项为各字段（`签名字段：<名称>（第 n 页）`），最后一项为“在页面上拖出位置”，默认第一个字段。
  - 选字段：上游 strokes/image 数据经 `signatureDataFromDialog` 转换，由 `signatureDrawingForField` 生成 `addDrawing`，经 `pdfPageState` 校验后加入草稿。
  - 选“在页面上拖出位置”，或没有可放入的字段：进入上游原有拖放流程，与上游完全一致，不弹出选择。
  - 取消：不改草稿。
- 预览模型合并时补上 `model.signatureFields`（与上游 `staticFormFills` 并列）。

## 真实浏览器冒烟（开发服务器）

- 文件：`smoke/pdf-signature-field-placement-smoke.mjs`。上游同名的 `smoke/pdf-signature-field-smoke.mjs`（表单设计“添加签名字段”）原样保留。
- 命令：`REPORT_EDITOR_CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium PDF_SIGFIELD_SMOKE_PRODUCTION=0 node smoke/pdf-signature-field-placement-smoke.mjs`

流程：
1. 打开上游签名对话框，手绘，点击“放置”。
2. 弹出“放入位置”，默认 PartyA，选项为 `['签名字段：PartyA（第 1 页）', '在页面上拖出位置']`。点击确定。
3. 草稿为 ink、线宽 1.6，`signatureField` 与来源模型身份一致，点集全部落在字段框 [72,120,312,200] 内。
4. 再签一次：不再弹出选择，直接进入上游拖放；按 Esc 后草稿不变。
5. 撤销/重做、刷新后草稿恢复。
6. 保存为修订 2。载荷等于草稿，下载字节等于保存字节，来源不变。
7. 重开修订 2，桥接 inspect 得到 `visuallySigned: true`。
