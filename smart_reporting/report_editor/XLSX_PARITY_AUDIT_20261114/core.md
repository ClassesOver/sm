**`source_boundary`, not a confirmed migration gap.** The complete pinned `apps/sheets/src/renderer/ExcelShell.tsx` Page Layout branch (2704–2897) exposes themes/colors/fonts, margins/orientation/paper, print area/breaks/titles, fit dimensions and sheet display/print options; it has no worksheet-background-image control. `page-layout-actions.ts:handlePageLayoutCommand` and `PAGE_SETUP_OP_FIELDS` implement those settings and no background operation. This is corroborated by the closed native save contract `apps/sheets/src/shared/desktop-api.ts:workbookPageSetupStateSchema` (1483; strict), `packages/xlsx-gateway/src/domain/workbook-dsl.ts:setPageSetupSchema` (841), and `packages/xlsx-gateway/src/gateway/xlsx-page-setup.ts:SheetPageSetupState/applyPageSetupState`: none defines a worksheet background image field, image relation, or write operation.
