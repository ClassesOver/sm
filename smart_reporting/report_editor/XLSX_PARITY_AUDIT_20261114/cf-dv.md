## Evidence and limits

Inspected full pinned serializer files and direct static diffs, source `univer-sync.ts` CF/DV builder/import sections, `App.tsx` CF preflight and installRuleDetail registration, `univer-rule-detail.ts`, source DSL `cfFormatSchema/cfRuleSchema`, source Rust worksheet x14 parsing/tests, and local read/schema/write/resource/preflight/checkbox/names implementations. Local assertion files inspected: `E/tests/conditional-formatting-snapshot.test.ts`, `conditional-formatting-split.test.ts`, `data-validation.test.ts`, `data-validation-read.test.ts`, plus `F/workbook-conditional-formatting.test.ts` and `workbook-data-validation.test.ts`. They cover roundtrip snapshots, unsupported/linked guards, prompts/errors/styles/date/time, x14 and preserved whitespace. **None was run in this audit.**

Highest-confidence residual gaps from actual transformations: CF imported dxf numFmt/borders cause whole-sheet skip; small-range text CF lacks source formula conversion; some linked/x14-only CF source rendering rejected by local completeness checks; DV list whitespace/formula2/checkbox import semantics differ; custom rule-detail decorations not established. These do not follow from identical dependency names and are not exact visual claims.

Source persistence boundaries to remove from migration-gap totals: CF timePeriod, equals/notEquals average, x14-only/mixed/custom icon saves, negative-data-bar/gradient write fields; DV listMultiple. Source itself offers broader UI/plugin shapes than its save accepts. Source DSL is narrower than the full native wire schema, so do not collapse those API layers into one support count.

Remaining bounded unknowns: actual browser evaluator results for every operator/threshold/date; tooltip/input/dropdown and rule-panel DOM behavior; render swatches/icons/gradient/negative bar positions; runtime behavior of all extended x14 combinations, legacy nonnumeric thresholds, and table/name alias cases. Imported field transformations above are confirmed statically; their complete visual or numerical impact was not tested. Runtime-adapter regex match counts are not feature counts.
