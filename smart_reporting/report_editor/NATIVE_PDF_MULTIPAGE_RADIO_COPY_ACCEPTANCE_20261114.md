# 跨页单选组完整复制验收（2026-11-14）

安全互斥单选组现在支持来源成员分布于多页。点击任意成员可复制完整字段组；重复保留原页面分布，粘贴以点击成员所在页对应目标活动页，保留全部成员的页间偏移。来源同页能力沿用本批校验。

## 行为与边界

- 复用既有安全2–64按钮完整组检查，保持实际当前值 V、默认值 DV、选项 Opt、状态 AS、外观 AP、必填及父子关系。复制使用独立引用，不从前端显示值重建来源字段。
- 引擎使用实际可信有序页面列表复核完整组，所有成员采用同一个页号偏移；各来源页内保持尺寸与相对布局，只允许统一平移。折叠到同页、重排、遗漏成员、篡改选项/状态或单独改变同页按钮位置均在写入前拒绝。
- 剪贴板按映射页面的 CropBox 原点分别平移和整体夹紧。缺少目标页或目标页面容纳不了整页选区时，整次操作拒绝，不残留部分草稿、不推进复制序号。
- 从非首成员页复制/重复/再复制均保持完整组。副本在当前画布页移动该页所有成员，其他页不动；删除、撤销、重做及草稿恢复仍以完整字段组为单位。
- 当前页成员可移动；保存前的复制组不支持改变选项或拆组。任意复杂多 Widget、异常状态、共享外观等不满足既有安全检查的来源仍受限；系统/跨文档剪贴板及实际签名复制未开放。
- 继续沿用原预览确认、保存修订与下载链。复核失败保留真实产物与诚实告警，不新增签发门禁。
