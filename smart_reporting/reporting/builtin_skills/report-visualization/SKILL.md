# Reporting 图表

## 阶段边界

- `visualization_section` 只处理任务 JSON 指定章节：读取签发的 facts/evidence，写入签发的脚本和图表输出路径，最后只调用一次 `submit_visualization_charts`。不得登记全局图表或冻结分析。
- `visualization_section` 只处理当前章节：读取受信 facts/evidence，生成并检查图表后调用 `submit_visualization_charts`；不处理其他章节或全局分析冻结。

## 选择

- 先明确管理问题、比较对象、期间、粒度和可用数据，再判断是否需要图表及其表达。
- 趋势与变化可使用折线、区间带、同比哑铃/斜率图或瀑布图；结构与贡献可使用排序条形、Pareto、漏斗或子弹图；分布与关系可使用箱线、散点、气泡或热力图。
- 选择必须符合数据语义：漏斗需要真实阶段顺序，目标或参考区间缺失时不补造基准，气泡面积映射规模而非半径，色阶、缺失值和极端值处理应清楚可辨。
- 这些示例不是模板、白名单或验收条件；不要求固定图表数量、类型或多样性。

## 六域决策

仅在当前章节有相关冻结事实时使用对应规则，不为覆盖六域强行作图。

- 收入：先用规模、结构与期间趋势回答，再用排序贡献定位科室、服务或项目；量价解释必须有同期间、同口径的工作量，不能把相关性写成原因。
- 工作量：分别呈现门急诊、出院或服务结构，必要时用趋势和贡献对象解释变化；不得以单项业务量代表整体，也不得在缺少可靠分母时暗示人均、床位或效率结论。
- 预算：只比较同版本、同期间的实际、预算和序时进度；用偏差排序、瀑布或紧凑对比定位集中领域，不把当前进度外推为全年结果。
- 全成本：呈现规模、结构、趋势和冲销；负值或冲销单独说明，不与正常成本对象混作贡献排序；单位成本必须有可靠分母，成本变化只可作为待验证的归因线索。
- 费控：呈现次均、药耗与高值耗材，并按可比服务、组织或期间定位异常；不得以次均费用替代全成本，也不在缺少对应事实时推断医保、DRG 或 DIP 原因。
- 资金：呈现现金余额、应收、回款和付款的期间变化与关联，必要时用账龄或回款结构定位压力；不得把应收变化等同现金变化，也不能在缺少现金或应收事实时判断流动性。

## 选图细则

- 连续期间的方向、拐点、波动或不确定范围可用折线、面积或区间带；期间较少时标注关键点，系列较多时突出管理关注对象。
- 两个期间或情景的差距与方向可用同比哑铃或斜率图；对象较多时按差异排序并减少非关键标签。瀑布图应明确起点、终点、正负方向和无法解释的剩余项。
- Pareto 图同时展示对象贡献和累计占比，类别按贡献排序；漏斗只用于真实阶段顺序和可比口径的转化或流失，没有阶段关系时改用条形图。
- 箱线图或小提琴图用于比较分布、离散度和异常值，样本过少时披露限制，避免暗示稳定分布。散点或气泡图用于连续指标关系、规模或象限，气泡面积映射规模而非半径。
- 热力图用于二维矩阵的高低、集中区或周期模式；色阶中心、缺失值和极端值处理必须清楚可辨。

## 事实与保密

- 使用当前 Task 实际注册的工具和工作区能力生成图表。所有数值必须由本轮不可变数据复算；视觉设计不能代替数据、口径和 citation 校验。
- 用户可见图表只使用业务名称、业务期间和必要指标。Dataset 路径、血缘信息、来源文件名和其他内部标识不得进入图表或用户可见报告；不得泄露内部路径。
- `comparability=reference_only` 时，标题和图注应明确包含“参考”，不得表述为严格同比。

## 可读性

- 图表只保留能改变管理判断的最小图表集合：每张图回答一个明确管理问题，并指向需要关注的期间、对象或偏差；同一指标、期间和粒度的同类趋势图不得重复。复用同一事实时，必须改为回答不同问题的互补表达，不能只换标题或颜色。
- 分类标签截断后相同、无法唯一识别对象时，不生成该图；改用末级业务名称、减少对象、横向条形图或表格。不得用相同的省略标签替代不同组织、科室或项目。
- 标题说明对象、指标和期间；检查坐标轴、单位、图例、标签、注释、边界、对比度和中文字体。
- TopN 或长标签优先使用横向条形图，并按数据密度调整画布高度、采用语义缩写或换行。少量指标优先使用紧凑对比图、哑铃图或表格。
- 默认目标像素至少为 1200 x 675，并为标题、坐标轴、图例和标签保留清晰边界。这些是可读性原则，不限制其他更合适的图形表达，也不构成固定模板或图表白名单。
- 同一 `chartId` 只服务一个正文块，不用同一趋势图重复填充多个段落。分类标签去重后仍不唯一时，改用末级业务名称、缩减 TopN 或改为表格；TopN 不超过 8，长标签随条目数增加画布高度。
- 系列数超过 4 且期间超过 6 时，不生成全量分组柱图，改用拐点月份、Top 贡献项、分面图或表格。图表与其解释块连续排布，避免图文跨页脱节；无法清晰表达时跳过该图，由脚本输出结构化诊断，不以密集图勉强覆盖。
- 轴、单位、图例和颜色语义在同一报告内保持一致；零点是否截断应与管理问题相符。标签密集时筛选重点、分面、排序条形图或定点注释，避免文字堆叠。颜色、线型、透明度和强调方式只服务于可读性与语义，不作为服务端审批条件。

## 复核

- `visualInspectionMode=vision` 时，每张最终图先调用 `inspect_chart`；若发现空白、截断、严重重叠或文字不可读，修正源脚本、重新生成并再次检查。普通警告和建议按管理问题与实际数据判断是否采纳。`visualInspectionMode=deterministic` 时不得调用该工具，由提交工具执行确定性检查。`view_image` 仅在当前 Task 注册时用于辅助复查。
- `submit_visualization_charts` 成功或返回 `already_committed` 后，`taskFinished=true` 表示当前 Task 已结束；不得继续调用工具、修改图表或重复提交。
- 多图总览可生成带文件名的临时联系表辅助定位问题。联系表只用于检查，不登记为报告图表，不通过 `chartIds` 引用，也不进入 Manifest、PDF 或 Word。
