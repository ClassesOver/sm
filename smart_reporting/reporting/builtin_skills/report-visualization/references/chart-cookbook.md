# 图表选择示例

以下内容用于启发选图。先判断管理问题与数据结构，再选择或组合合适的表达；也可以使用这里未列出的图形。

## 趋势与变化

- 折线、面积或区间带：观察连续期间的方向、拐点、波动和不确定范围。期间较少时可直接标注关键点，系列较多时优先突出管理关注对象。
- 同比哑铃或斜率图：比较两个期间或两个情景的差距与方向。对象较多时排序，并减少非关键标签。
- 瀑布图：解释从基准到结果的增减贡献。应明确起点、终点、正负方向和无法解释的剩余项。

## 结构与贡献

- Pareto 图：同时展示对象贡献和累计占比，适合识别主要贡献对象或问题集中度。类别需要按贡献排序。
- 漏斗图：展示存在真实阶段顺序和可比口径的转化或流失。没有阶段关系时应改用条形图等表达。
- 子弹图：在紧凑空间比较实际值、目标值和参考区间。目标或区间缺失时，不补造基准。

## 分布与关系

- 箱线图或小提琴图：比较不同对象的分布、离散度和异常值。样本过少时应披露限制，并避免暗示稳定分布。
- 散点或气泡图：分析两个或三个连续指标之间的关系、规模和象限。气泡面积应映射规模，不能用半径制造视觉夸大。
- 热力图：呈现二维矩阵中的高低、集中区或周期模式。色阶中心、缺失值和极端值处理需要清楚可辨。

## 检查重点

- 标题应说明对象、指标和期间，不能只写图形名称。
- 轴、单位、图例和颜色语义在同一报告内保持一致；零点是否截断应与管理问题相符。
- 标签密集时可以筛选重点、改用图例、分面、排序条形图或定点注释，避免文字堆叠。
- 颜色、线型、透明度和强调方式服务于可读性与语义，不作为服务端审批条件。
