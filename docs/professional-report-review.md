## 已接入的修复

1. 复用既有 Agno 阶段指令机制，向真实分析、提纲和写作 Agent 注入对应专业准则。按实际任务分章，不强制生成七章或空领域章节，不恢复章节数硬上限。
2. 在既有内容复核中加入有限专业诊断，参与原有有预算的纠错评分与回退，不创建新的返工循环。
3. 发布质量记录和编辑器当前正文使用相同诊断，保留机器码、审阅编号与具体原因；professionalReview/1 进入质量输入身份。
4. 缺少医院配置的新报告默认署名改为“编制单位待确认”，不把软件供应商自动作为医院编制主体。显式配置及历史冻结署名按原样读取；新默认值影响新解析 Profile 的哈希，不能据此重写历史产物。
5. 发现证据等级转换为服务端派生的写作边界，同时进入提纲、章节规划、整章和逐块写作。事实只按已核实范围描述，数值贡献不证明因果，相关关系不能评价效率，假设只能提出验证方向，缺项不能生成经营目标。高优先级缺项保留可见，不因优先级高而被称为已核实结论；确定性降级提纲也遵循此边界。
6. 当前章节发现的任一来源身份或指针不可用时，只对模型视图隐藏该发现原摘要并标记证据缺口，保留冻结卡片供审计。当前可用证据继续展示；整体分析旧摘要不再绕过发现选择重新进入正文模型。来源告警独立于正文纠错保留，生成及下载继续。
7. 针对 R015/R032 等意见，补充归因须由同一条冻结指标的完整分组总体证明，并匹配指标、期间、范围、单位和结构化分组身份；复用现有完整 Top-N 总体校验，不以 Top-N 前缀或两条不同来源拼接证明。拒绝升级的归因保留补证文件、缺口及核查方向；可核实的直接分解同时绑定补证和基础事实文件。数值闭合仍不证明分类含义、会计归属或业务因果正确。
8. 直接分解通过时，卡片标题及摘要由已登记指标生成中性数值表述，不沿用补证中的任意经营原因标题；数值闭合不自动将行动性标为高。完整来源及原始补证仍保留供核查。

当前有限诊断覆盖：执行/完成率与超预算判断相反、待核实预算提前定性、零预算计算执行率、剔除零预算/零实际记录、由相同月值推断期末余额、用开单收入判断现金、以相关系数替代效率、负数认定为冲销、集中记录认定为一次性入账、由规模/占比认定浪费，以及已声明口径不一致仍计算结余。

诊断只给软告警。没有告警不代表任意业务语句正确；跨主体或含多项比率的复杂表述不靠数字就近匹配强行判定。已核验身份且可读的 PDF/Word 继续下载，质量问题不转为正式发布许可的否决项。

证据写作边界是结构化模型输入约束，不是对任意自然语言的完整证明。来源可解析也不代表业务解释正确；未知或历史未声明的证据等级按缺口处理，不自动补成已核实。当前来源核查结果不改写历史文件或其哈希。

## 仍需真实证据的工作

- 预算是年度数、正式月下达数还是累计数，以及版本和重复挂载规则，须由真实指标定义确认。
- 医院认可的收入归属、成本归集/分摊阶段、内部结算及科室/院区映射，须经业务配置和数据核查确认，不能从开单收入减成本推断利润。
- 真实零与未采集/未映射状态、异常凭证、负数及一次性事项性质，仍需真实证据。
- 图题、像素、正文、附表的完整跨载体语义仍需共同冻结事实及实际产物回放。本次不声称已重绘或核准压缩包中的旧图表。
