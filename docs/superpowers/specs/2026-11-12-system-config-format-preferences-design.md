系统配置采用左侧分类目录、右侧设置表单。页面分类为模型与服务、报告运行、编辑与导出。日常页面保留12项维护设置，执行协议、调试、追踪与访问日志由部署配置维护。中文名称为主，环境变量名作为辅助说明；支持常用项搜索、修改差异、版本和实际生效状态。

系统配置仅呈现日常维护项；移除高级参数入口，搜索不再带回底层协议参数，部署路径、监听地址等继续由部署配置维护。去掉空分类和逐项重复的重启说明，来源及环境变量在标签提示中查看。正文面板最大 908px、表单最大 720px，随内容自然高度展示，不用空白或冗余参数撑满页面；顶部五格式方角页签仍横向占满。

偏好管理顶部为横向占满的 MD / XLSX / PPTX / PDF / Word 五个格式页签；不再增加五个一级菜单。各格式内按「常用」「页面与排版」「页眉页脚」「落款」「表格与图表」「导出」切换设置区域，仅显示该格式有意义的分区。根据用户关于冗余配置与页面被撑开的最新反馈，主区统一采用设置/预览视图切换，各屏宽均不常驻并排；内容面板最大 908px，表单最大 720px，按内容自然高度展示，不纵向堆叠。预览按需读取已保存草稿，修改中明确标注样例未包含当前输入，保存版本变化清除旧样例；切换视图保留表单，校验错误返回设置视图。版本历史按需打开，不常驻堆叠在表单下面。

## 落款设计（必备）

落款内容为默认维护区，四种 Office 格式的字体、字号、颜色、对齐、加粗收进默认折叠的「落款样式」；校验错误自动展开定位，不把低频样式纵向铺开。Markdown仅维护内容。

落款为独立的内容与样式模块，页脚、水印、封面中的署名不能代替正文或交付物末尾的落款。

| 类别 | 配置内容 |
|---|---|
| 内容 | 署名、生成日期、可选附加说明；署名为普通文本，不新增组织对象或人员目录 |
| 日期 | 默认使用本次报告修订的生成日期，选择日期显示格式；同一修订的预览和重复下载不改变日期 |
| 排版 | 字体、字号、颜色、行距、署名与日期间距、与前文的间距、对齐方式 |
| 位置 | 按格式选择合法落点；默认遵循下表，不开放任意绝对坐标作为普通维护操作 |
| 内容复用 | 共用一份署名与日期来源，各格式可独立调整样式；从当前有效署名配置初始化，不用登录用户名或示例名称猜测落款 |
| 预览与校验 | 预览展示完整落款，长署名自动换行；检查遮挡、溢出、重复添加和与正文分离的问题 |

| 格式 | 默认落款落点 |
|---|---|
| MD | 正文末尾独立的 Markdown 段落，署名与日期分行；不依赖仅个别阅读器支持的对齐 HTML |
| XLSX | 说明工作表末尾的原生单元格区域，不把落款混入业务数据表体；说明页同时进入打印范围 |
| PPTX | 最后一页的原生可编辑落款文本区域；空间不足时使用结束页，保持正文与落款均可读 |
| PDF | 正文结束后的独立右对齐落款块；署名和日期保持在一起，布局与页脚互不覆盖 |
| Word | 正文结束后的原生段落，默认右对齐；使用段落分页属性保持落款整体，支持后续编辑 |

落款默认必备，不提供跨格式总开关将其整体移除。新偏好应用前必须有有效署名；已完成任务保持其冻结的落款身份。已有模板明确的落款位置优先复用并绑定本次内容，不能追加重复落款或沿用模板示例署名、日期。附录不再重复添加落款。

## 页眉页脚与常规 Office 偏好

Word/PDF/XLSX 的页边距先选择常规、窄、宽或自定义；仅自定义展开四边毫米数值，至少保留20毫米可打印宽高，错误直接定位对应字段。

页眉页脚使用表单选择左/中/右区域、文本样式、位置及分隔线；动态内容通过「插入字段」选择报告标题、分析期间、生成日期、文件名、页码/总页数等受支持字段。每种格式只显示自身支持的字段。所有页码使用真实页码字段或导出引擎分页结果，不能手写页码。

| 格式 | 纳入设计的设置 |
|---|---|
| MD | 标题级别、列表与表格写法、目录、代码块、图片说明、引用和末尾落款；不存在物理分页页眉页脚，不显示其设置 |
| XLSX | 默认字体、字号、对齐、自动换行、行高/列宽；表头、边框与条纹；小数位、千分位、百分比、日期和负数显示；冻结表头、自动筛选；打印纸张、方向、边距、打印区域、重复标题行、缩放与分页；左/中/右打印页眉页脚、页码；说明页落款 |
| PPTX | 页面比例、主题色与字体、标题/正文/注释样式、内容密度、图文布局、图表和表格风格；日期、页脚、幻灯片编号及标题页隐藏规则；末页落款。页眉类信息进入标题或版式区，不照搬 Word 分页语义 |
| PDF | 纸张、方向、边距、封面与目录；正文/标题/图注样式；页眉页脚、首页差异、奇偶页差异、页码起点；表格跨页、图表与落款分页；书签、固定字体嵌入与图像输出质量 |
| Word | 纸张、方向、边距；字体、字号、标题样式、段前段后、行距、首行缩进；封面、原生目录、页码；页眉页脚、首页不同、奇偶页不同、页码起点；表头重复、表格跨页、图表标题与编号；独立落款段落 |

PDF/UA交付始终嵌入字体，不提供无效的关闭开关；历史embedFonts=false快照保留读取兼容并返回具体提示，文件继续生成。字体选择限定为实际渲染环境具备的字体；缺失字体明确显示替代情况。数值格式仅控制显示，不改变原始数据、公式结果、统计口径或精度。Office 文件保留原生可编辑段落、表格、文本框和工作表，不以整页图片代替。

公共署名、日期、主题等只维护一个默认来源；PDF 与 Word 可以继承同一默认排版，再分别配置差异。页眉、页脚、水印、封面署名、正文落款各自有清楚名称和预览位置，避免同一个内容在多个入口竞争。

## 系统环境变量纳管边界

建立项目配置清单，只纳入代码明确声明和读取的变量，不枚举并公开全部进程环境。每项登记类型、单位、校验、默认来源、敏感性、依赖条件和真实生效方式。

- 报告模型、运行限额、业务功能开关等按实际读取链路提供可维护设置；能按任务初始化的配置在下一任务生效，进程初始化项标明重启后生效。
- 系统数据库连接、加密主密钥、监听端口、构建镜像和引擎路径等部署基础项首版只展示脱敏状态及维护说明；不提供修改后可能使管理入口自身失效的普通表单。
- 密码和令牌复用既有凭据加密与引用机制，只显示配置状态，允许明确替换；不回显或写入审计明文。
  - 已接通模型服务凭据替换：复用 CredentialVault 加密，独立 system_credentials 不可变记录，草稿/发布版本仅存引用；发布并重启后消费，历史恢复保留旧凭据。元数据服务令牌同样支持服务端替换，不新增日常表单参数。缺密钥时明确告警并回退部署启动值，不误报管理版本已生效。
- 署名、页眉页脚、水印等已有环境变量归属「偏好管理」，系统配置只显示其来源与跳转入口，避免两处独立编辑。
- 展示已保存版本、当前有效版本及生效时间。管理配置、部署初值与内置默认的来源明确可见，不通过直接修改全局 os.environ 实现运行时更新。

## 版本、运行与兼容原则

编辑器导出与预览按格式冻结默认叠加明确修改差异，避免将PDF完整默认写成Word的通用覆盖；Word单格式编辑采用Word基线。实际双格式字体、导出提交及重启回读已有专项证据；历史恢复已接通各格式默认、页面和落款上下文的来源修订继承，缺失旧字段不会残留新版值；预览、导出提交及重启回读已有证据。另已通过真实数据库快照、重启读取、派生修订继承及五格式实际生成的代表性配置验证；这不替代所有正式入口、历史编辑和重复下载的完整冻结审计。

分别维护系统配置和全局偏好的草稿及有效版本，沿用现有保存、应用/发布、差异、CAS 并发保护和回读机制。恢复旧版本产生新版本，不覆盖历史记录。

全局偏好作为新任务默认值。明确的单次任务要求、上传模板布局和报告编辑器中已经确认的设计优先于全局默认；落款缺失时补齐，模板示例内容必须重新绑定。业务事实、安全边界和发布契约不能被外观偏好覆盖。

任务创建时冻结所用系统配置版本、偏好版本及解析后的有效值；运行中修改只影响后续任务。已有修订的预览、恢复和再次下载不因为全局偏好更新而变样。当前浏览器本地导出选项只作为单次编辑意图，不升级为共享全局默认。

已有部署配置作为首次纳管初值；首轮上线维持现有效果，不自动重写历史报告。服务端渲染、编辑器预览和各格式导出读取同一份有效配置。落款缺失、排版或预览校验失败必须返回具体原因，但已生成且身份可核验的产物仍按项目非阻断签发契约保留下载。
