# 中文标准可视化 P0–P3 验收清单

本 PR 以 code 分支为基线，只包含实现、定向回归及合成测试夹具。

| 项目 | 交付 |
|---|---|
| P0-1 | 缺失说明使用已配置的中文系列名，保留缺失空位 |
| P0-2 | 标注避让显示坐标下的数据折线，处理变换、裁切、线宽和断点 |
| P0-3 | 失败、取消、组件和最终组合的尝试成本可追溯，墙钟与累计分开 |
| P1-1 | 使用结构化目录纠正可唯一定位的绑定，不因列名相同而替换业务指标；保留单位 |
| P1-2 | 复用语义消歧核对期间；证据需落在当前字段；无法确定时软告警 |
| P1-3 | 保留原计划、分页映射、输入/输出身份、预检、Coding 进入和提交事件 |
| P2-1 | 复用首次预检，保留标准证明的独立重编译 |
| P2-2 | 验证输入/脚本/图片身份后复用组件 PNG，最终执行与视觉回执仍重新产生 |
| P3-1 | 冻结快照、CAS 编辑、受影响图重绘、历史、四格式静态图片导出和独立下载授权 |

## 验证与边界

- 定向覆盖单位/绑定/期间、路由/图片篡改、数据修订状态/API、XLSX/PPTX 桥接及项目规定的发布非阻断契约；不运行重复完整测试。
- 真实本地 CodeMode、Matplotlib、PDF/Word/PPTX/XLSX 导出联测使用合成数据：150→180、分页图片及来源单元格一致。视觉服务使用测试替身；不能作为生产视觉验收。
- PPTX/XLSX builder 写文件后异常时保留可读取身份的产物，具体失败仍返回为告警，不能标记验收通过。
- 已展开的历史分页计划保持既有展示标签和值域；修改标签或越出值域可能进入 Coding。未证明这类编辑仍能走标准模板。
- 原正文、表格和图注结论不自动重算，导出说明需复核。
- 生产 AgentOS、真实视觉服务、历史同字节反事实、生产成功率和 P95 提速未验证。
- 不引入 Plotly、宏或 Office 原生图表；下载文件不自动回传。
