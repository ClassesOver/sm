# XLSX 与 PPTX 人工修订的可见核验状态

本轮在既有人工保存路径加入文件内可见说明。XLSX 首张工作表与 PPTX 第一页明确显示“本修订待核验”、当前/父修订，以及数值、解释与建议尚未重新核验。原有段落标签和来源记录仅供追溯，不能作为本修订已获确认的证明。

这是一项有限的交付状态改进，不执行语义模型、不推断撤销原因、不重算数值、不把旧段落逐句改成新结论。旧可见段落标签保留；精确支持重审仍未完成。

## 实现与边界

- 仅向现有 ZIP 包补充/更新专用说明部件与目录关联；同名业务表/正文不被覆盖。XLSX 保留原单元格坐标和公式，调整局部定义名称索引及打开位置；PPTX 保留原形状、动画、媒体和页面尺寸，说明页使用原包内布局。原有业务页码仍按原正文编号。
- 重复保存依部件路径和内部身份识别同一说明。真实原生引擎执行工作表改名/重排、幻灯片重排后再保存，两项测试均确认不会重复增加说明。
- 说明在修订分配后、写文件和计算签发身份前加入。失败分别返回 workbook_revision_notice_unavailable / pptx_revision_notice_unavailable，原已生成文件继续身份核验与下载；不伪称说明已生成或验收通过。
- 无前端依赖、数据库迁移或查询权限变化。没有新建独立业务白名单或兼容旧 Profile。

## 验证事实

1. 新功能缺模块两条红例；独立 helper 首轮一条测试将 A5 当作待核验正文，实际布局为 A6，是测试装配错误，纠正后两条通过，未计作产品红例。
2. 真实隔离 PG 集成先复现 XLSX 未改重新导出仍无可见核验状态（1 failed / 3 deselected），随后接入保存路径。
3. 相关 helper、工作簿、幻灯片保存、两项新增精确 HTTP 下载故障注入及静态守卫：40 passed（15.80 秒）。
4. 三项实际集成：XLSX 标题编辑、XLSX 未改重新导出、PPTX 标题编辑，均先由真实管理服务撤销原件，再经真实 ASGI HTTP/cookie/CSRF 保存、签发和下载：3 passed / 1 deselected（52.18 秒），隔离库清理成功。父/新修订递增、当前支持 unverified/无旧引用、实际文件大小/SHA、编辑内容和父文件字节均核对。文档路径行为未变，未重复该集成。
5. AGENTS 要求的非阻断节点加原有 XLSX/PPTX 保存故障集合：93 passed / 2 deselected（68.73 秒）。强化 helper 对所有原 ZIP 非目录部件逐字节保留后，仅定点补两项：2 passed（12.75 秒）。集合有重叠，不累计为独立测试总数。
6. 只读复核无发现；受影响 Ruff 与 git diff --check 通过。保留第三方依赖弃用警告，未跑完整项目测试。

实际文件与精确父清单/索引、全部注册源文件均直接从此次测试留存。两份 XLSX 与一份 PPTX 各渲染 5 页，共 15 页；联系图均检查，三份首页进一步单页查看，中文/修订号/待核验说明可读，受检页未见明显截断或重叠。原 XLSX 结论列窄、留白和重复文字仍存在，不冒称完成整体美化、浏览器或四宽度验收。
