# 正式指标计算来源附录：隔离技术证据

本目录证明冻结正式结果的中文计算说明能进入实际PDF/Word附录。包含原始登记源字节、索引、验证与展示载荷、实际PDF/Word、四页渲染及源码/日志。不是业务签认，也不是首次公开报告或真实数据库集成验收。

## 本轮改动

- 展示精确指标/口径版本、登记Decimal原值、半开期间、匹配取数回执和具体限制；比率只解释冻结定义，不冒称操作数已核对。
- 无精确依赖版本不借最新版；来源basis不匹配时拒绝使用数值与说明。
- 修正表格来源漏掉正式方法与期间；合法长说明不静默截断，整体16KiB字节预算保持。
- 正式说明构建故障已登记HTTP故障注入及签发守卫，仍返回失败验收和真实PDF/Word下载。

## 证据边界

使用内存仓储、合成CSV和冻结事实；实际WeasyPrint/pandoc渲染与进程内ASGI下载，不使用业务.env、真实模型或StarRocks。生成日期2026-09-30来自原夹具，不是本次运行日期。rendered/source.md为为原生渲染添加合法标题与章节的投影；原登记Markdown原件在rendered/registered下，二者身份分别核对，不声称原字节相同。

日志中的红例与装配失败分别保留。formal-source-http-and-render.log为HTTP夹具失败但原生渲染1passed；最终HTTP结果以fault-4为准。测试集合有重叠，不累计独立总数；不把skip或deselected算通过。

视觉只核对两格式各两页及附录单页；中文、精确数值和限制可读，但留白多、范围未登记，不视为完整视觉验收。未覆盖完整知识原文附录、PPTX/XLSX来源附录、真实模型/数据库/业务确认或完整38案例/§5/T1–T9。
