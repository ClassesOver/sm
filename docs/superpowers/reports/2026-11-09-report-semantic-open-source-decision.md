# 开源采用决定与尚缺验证

日期：2026-11-09；状态：部分证据就绪，T1尚未完成。

采用项目已固定的Agno3.1.2公开Knowledge接口，复用SQLGlot和现有数据集/trace，先实现独立新契约；没有引入或复制MetricFlow、Cube、OpenMetadata运行时。

OpenMetadata已读取的schema支持将指标定义、单位、粒度和资产引用分别建模；不采纳其任意表达式语言作为本项目可执行公式。MetricFlow/Cube在粒度与重复关联方面的具体算法仍待实际源码及测试审计，不将产品介绍当证明。
