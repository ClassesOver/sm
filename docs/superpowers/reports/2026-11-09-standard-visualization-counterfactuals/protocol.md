# 标准可视化：有限反事实实验规则

本轮承接用户选择的“补齐原计划反事实实验与优化证据”。研究基线为合并 PR 195、197、198、199、200、202、203 后的 `7550d1da392dcf928e81c3b8478b953c49c433b5`。本文件先于本轮实验提交；历史研究材料不覆写。实验脚本及夹具随后提交，因此这是预先登记的有限假设，不是盲法预注册研究。

## 冻结与裁决

- 全部为合成数据，无生产任务、模型调用或真实业务数据。保留业务意图、输入原始字节、计划 JSON、实际输出/诊断及 SHA256；记录代码、依赖锁、OS、locale、字体身份。
- 每对只改变下表指定的一项。改单位 metadata、期间值或无关 metadata 会改变输入身份；它们是相同数值/业务意图的输入扰动，不能声称冻结字节相同。规划参数变化必须保持输入字节相同。
- 数值预期只用独立 Decimal/Fraction 与固定业务声明计算；不得调用生产换算/变换函数生成预期。身份、数值、几何、视觉分别裁决。
- 现有实现满足目标时，不制造 minimal_fix 或 Flint adapter。Flint 仅作机制参考；未实际执行其测试不得标记运行通过。没有本地依赖时，不绕过既有安装限制。
- 捕获到非预期结果时，保留反例并解释，不自动放宽断言。发现生产缺陷另列最小修复任务。

## 执行矩阵

| U1 金额显示 | displayUnit 元→万元 | 金额 `[250000,-12500,0,null]`，独立预期 `[25,-1.25,0,null]` 万元；保留缺失与符号 |
| U2 复合单位 | displayUnit 元/人次→万元/人次 | 人均费用不能丢分母；当前未登记复合换算应拒用，不等于公式算错或自动换算支持 |

| P1 比较年份 | previous source periodYear 2024→2023 | 两份冻结来源不变，错年须诊断；正确按月对齐逆序来源得到 `[10,9],[20,18]` |

## 验证与交付

1. 运行新回放脚本，输出逐例 JSONL、原始输入与计划、布局 PNG/图元测量和环境清单。
2. 为本轮证据运行 D2 单个 PNG 集成节点和 D3 必需节点，保存命令、退出码、原始日志和测试源码身份。它们不等于 AgentOS 真实模型报告测试。
3. 检查每对变化路径与冻结身份，独立只读审查脚本、oracle 与结论映射；不将代码审查当业务审查或视觉盲评。
4. 输出优化建议与清单：已证明、未验证、材料不足分列；不报告生产支持率/最终交付率/回退率、median/P95或性能收益。只有正确性成立、同候选至少10组成本配对及真实trace具备后才讨论性能推断。

外部验收仍需独立业务口径确认、干净环境复现及两位视觉盲评。字体覆盖与文本bbox仅证明确定性技术约束。研究交付不表示原计划全面验收完成，不自动合并本轮分支。
